Easy Publish 0.1.6 将公众号模板移到账号管理，并改为上方输入原文、下方查看各平台最终预览。文章发布直接使用账号管理中已开启的兼容账号，无需再次勾选。

## 文章编辑与预览

- 上方集中填写标题、作者、封面等资料，正文使用一个输入框。新文章输入纯文本，点击整理后由内置 OpenCode 转为 Markdown；原文独立保留。
- 下方按账号展示最终预览。公众号使用各自设置的六套模板，知乎、雪球等按平台支持的格式显示。
- 模板在账号管理中选择，创建任务时冻结；修改模板不会改变已排队内容。
- 文章页移除右侧账号勾选区，自动跟随账号管理开关。已提交、已发布和结果待确认的平台仍默认跳过，需要再次发布时显式加入。视频保留原有选择方式。

## 内置原文整理

- 三种安装包内置固定版本 OpenCode，无需另外安装或提供模型密钥，优先使用官方免费模型入口。
- 仅点击整理时发送原文；保存、切换账号和模板只更新本地稿件或预览，不调用模型，不自动发布。
- 失败、取消及免费服务限流保留原文；修改正文后旧结果失效，过期任务不能覆盖新编辑。
- 使用 Easy Publish 独立目录及配置，不读取个人 OpenCode、浏览器资料或系统钥匙串，不自动改用付费模型。
- 原有 Markdown 稿件及 MCP agent 写好的文章仍可直接预览和发布，公众号沿用账号模板。

## 升级与验证

完全退出旧版后替换应用，保留应用数据目录。已有稿件、账号开关及发布记录保留，公众号新增模板设置默认使用清爽蓝；旧批次继续使用创建时的稿件模板。

免费模型需联网，服务可用性和配额由提供方决定；生成后请核对预览。实际测试环境中的免费请求触发服务端额度限制，已确认应用能快速停止并保留原文，尚未取得真实模型整理成功的结果。真实平台登录和发布仍受账号权限与平台验证影响。
