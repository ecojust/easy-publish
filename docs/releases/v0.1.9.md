Easy Publish 0.1.9 改为直接编辑 Markdown，再通过本地 Wenyan CLI 查看模板预览，移除 OpenCode 和模型生成步骤。

## 文章编辑与预览

- 正文直接输入 Markdown，也可导入 Markdown 文件；标题、作者、摘要、封面等资料集中在上方。
- 点击右上角“预览”，打开各平台的最终排版。微信公众号使用账号管理中保存的 Wenyan 模板，八款官方主题和旧兼容主题继续可用。
- 编辑、预览和切换模板都在本地完成，无需 API 密钥或免费模型额度；预览不会自动保存或发布。
- 移除“润色生成”、免费模型设置、后台生成任务及安装包中的 OpenCode 程序。其他 agent 写好的 Markdown 可继续通过 MCP 保存、预览和发布。

## 旧稿保留

- 旧版已经成功生成且与当前原文一致的 Markdown 继续保留。
- 尚未生成或原文已修改的稿件，以最新原文迁入 Markdown 编辑器；已导入图片保留。可通过“查看旧版原文”查看原始内容。
- 修改稿件不会覆盖旧原文归档，历史发布任务继续使用创建时的内容和模板。
