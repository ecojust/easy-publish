Easy Publish 0.1.8 接入 Wenyan 官方模板排版，完善“纯文本 → OpenCode 润色 → 最终预览”流程。

## 文章润色与模板

- 输入纯文本后点击“润色生成”，OpenCode 改善表达、衔接和结构，并保留原意、事实、数字与图片位置。原文独立保存。
- 通过右上角“预览”查看最终排版；预览和切换模板不调用模型，也不自动发布。
- 内置与 oDesk 使用的 Wenyan CLI 相同的官方渲染核心，提供默认经典、橙心、彩虹、青金石、思源、玉米、紫色、物理猫八款官方主题。
- 微信公众号的模板仍在账号管理设置；模板缩略图、文章预览与微信发布共用渲染链路。所需运行依赖已经内置，无需安装 Node.js 或 Wenyan CLI。
- 尚未连接账号时可查看默认排版；关闭自动发布或已经发布过的账号仍可预览，其发布筛选规则保持不变。
- 已有 Markdown／MCP 稿件可直接预览，也可“复制为润色草稿”，保留原稿后生成新的润色内容。

免费模型仍受提供方的服务配额限制，失败时保留原文，不自动使用收费模型。本版本不改变模型服务，也不代表已通过用户真实账号发布验收。
