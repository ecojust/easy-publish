Easy Publish 0.1.5 增加默认发布账号开关和多平台字段适配，修正视频账号登录流程，并保留 0.1.4 的应用内存储方式：不访问系统钥匙串，也不读取个人浏览器资料。

## 新增

- 参考 oDesk 丰富公众号排版，升级四套原有模板，新增森林来信与黑金画报；标题、引用、代码、表格与图注各有完整样式。模板卡片展示真实排版缩略图，预览与实际发布共用渲染器。

- 账号管理增加“发布时默认选中”。文章与视频工作台自动选择对应的已连接账号，已提交／已发布／结果不明的平台仍默认排除，手动选择不被常规刷新重置。MCP 使用相同默认规则。
- 同一稿件可完整填写多个平台的字段，每个平台只使用需要的内容。例如抖音忽略自定义封面、B 站原创忽略转载来源；原稿保留，真正必填项继续检查。

## 修复

- 对照 social-auto-upload 的登录、检查和上传流程，优先验证并复用 Easy Publish 已保存的会话；需要重新登录时再打开浏览器。
- 将抖音、小红书和视频号的登录状态与视频上传控件分开判断，并处理扫码后打开的新标签页；空白页和平台验证提示不会被当作登录成功。
- 增加连接阶段提示和“取消连接”；取消会关闭该账号的工作进程并清理临时目录，保留账号及已保存会话。
- 发布流程在新建 Release 草稿后等待短暂的可见性同步，保留来源和附件校验。

完全退出旧版后替换应用，保留原应用数据目录。0.1.4 已连接的账号继续复用应用内会话；从 0.1.3 或更早版本升级时，旧账号需要重新连接，公众号凭据需重新填写，稿件及发布记录保留。校验值见附件 `SHA256SUMS.txt`。

上游 CLI 中抖音、小红书、视频号等同样通过浏览器执行登录与投稿；B 站采用 biliup 命令行上传。分类与源码依据见[上游登录方式对照](https://github.com/ecojust/easy-publish/blob/master/docs/upstream-authentication.md)。本版本对齐其会话复用和登录流程，仍使用 Easy Publish 的任务监督与单次提交保护，并非直接执行整个上游 CLI。
