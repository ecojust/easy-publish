Easy Publish 0.1.4 将账号存储改为只使用应用自己的数据目录，启动和连接账号不再通过系统钥匙串读取加密密钥。

## 修复

- 移除 keyring 及其打包后端。账号凭据和登录会话继续加密保存，密钥保存在应用目录内。
- 明确设置发布浏览器的钥匙串禁用参数；浏览器使用独立的临时配置，只恢复 Easy Publish 保存的会话。
- 升级后提示旧账号重新连接；保留稿件、素材、账号信息、发布历史及旧版密文，不为迁移请求钥匙串权限。
- 本地密钥缺失或损坏时停止读写并提示处理，不静默替换密钥。

完全退出旧版后替换应用。浏览器账号重新连接一次；旧公众号账号需移除后重新添加并填写 AppID／AppSecret，历史任务保留。旧版钥匙串条目不会被读取或删除。安装包校验值见附件 `SHA256SUMS.txt`。

密钥和密文同存应用目录，macOS／Linux 使用私有文件权限，Windows 继承当前用户应用目录权限；能读取完整应用目录的进程可能解密这些账号信息。

最低系统为 macOS 13.5+／Windows 10+ x64。macOS 仍使用 ad-hoc 完整性签名，未配置 Apple Developer ID 和公证；Windows 未配置商业代码签名。

## 验证

本地最终源码通过 439 项 Python 测试（另 1 项 Windows 专用检查跳过）、21 项 UI 测试与 13 项 Rust 测试。三平台构建和安装包启动检查全部通过；两种 Mac 各通过 432 项引擎测试，Windows 通过 428 项，其余为平台专用或可选浏览器检查。冻结包验证本地密钥创建、加密凭据保存／删除、MCP 和正常退出，并检查未包含 keyring；Mac 另验证 DMG 中应用的签名及精简环境启动。
