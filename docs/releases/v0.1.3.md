Easy Publish 0.1.3 提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包，用于将一篇文章或一个视频发布到多个已连接账号。

## 本版功能与修复

- 文章平台：微信公众号、知乎、大鱼号、雪球；视频平台：抖音、快手、小红书、微信视频号、哔哩哔哩。
- 支持再次发布旧稿，默认不勾选已有提交／发布／结果待确认记录的平台，可手动选择重新发布。
- 内置清爽蓝、墨色杂志、暖色手记、理性科技四套文章模板，发布时自动适配目标平台格式，预览复用同一转换。
- 内置 12 个 MCP 工具。在“设置 → AI 助手与 MCP”复制配置，其他 agent 可通过已连接账号导入素材、保存稿件、预检、发布和查询结果；文章／视频账号按类型隔离。
- 修复抖音扫码进入创作者首页后一直连接中的问题。
- 修复小红书上传尚未完成就操作编辑器，以及视频号上传接近 98% 时内部页面重载导致提前关闭的问题；等待处理、重新定位编辑器并仅提交一次。
- 保留 macOS 内置 Python 签名兼容修复，普通用户无需安装 Python、Node.js 或开发工具。

## 下载与安装

| 系统 | 安装包 |
| --- | --- |
| macOS Apple Silicon（M1–M5） | [Easy-Publish_0.1.3_macos-arm64.dmg](https://github.com/ecojust/easy-publish/releases/download/v0.1.3/Easy-Publish_0.1.3_macos-arm64.dmg) |
| macOS Intel | [Easy-Publish_0.1.3_macos-x64.dmg](https://github.com/ecojust/easy-publish/releases/download/v0.1.3/Easy-Publish_0.1.3_macos-x64.dmg) |
| Windows x64 | [Easy-Publish_0.1.3_windows-x64-setup.exe](https://github.com/ecojust/easy-publish/releases/download/v0.1.3/Easy-Publish_0.1.3_windows-x64-setup.exe) |

升级前完全退出旧版。Mac 打开 DMG 后替换“应用程序”里的 Easy Publish；Windows 运行安装程序。附件 `SHA256SUMS.txt` 提供安装包校验值。最低系统为 macOS 13.5+／Windows 10+ x64。

macOS 使用 ad-hoc 完整性签名，尚未配置 Apple Developer ID 和公证；Windows 尚未配置商业代码签名。首次使用浏览器平台可在应用设置中准备发布浏览器。

## 验证与产物来源

本地通过 417 项 Python 隔离测试、21 项界面测试和 13 项 Rust 测试；三个系统均通过冻结引擎／MCP 与原生宿主启动检查，两种 Mac 还通过从 DMG 复制应用后的签名和精简环境启动检查。平台操作使用 HTTP／浏览器 fixture，尚未完成真实账号发布及用户 M5 上传验收，原生宿主 smoke 不代表完整原生 GUI 实测。
