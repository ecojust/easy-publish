## 行动记录

### A1 · 参考实现和确定接口

- 阅读仓库协作与历史，创建功能分支；分工桌面壳、前端、微信适配、文章/视频适配与本地引擎。
- social-auto-upload 固定参考 `3847fff01f5434a8a32829833163cd6723cabc59`（MIT）；oDesk 固定参考 `d062c05b3442f45205ff83cc28497d435fccce99`（MIT）。参考源码位于仓库外 scratch，持久来源说明随源码保存。
- oDesk 微信路径实际调用 draft/add，只能据此确认草稿创建。新实现区分草稿、提交审核、已发布、结果不明，不能据上传完成宣称发布成功。
- 采用 Tauri 2 + React / TypeScript + 打包 Python 发布引擎。文章与视频分开；文章预定公众号、知乎、大鱼号、雪球，视频预定抖音、小红书、视频号。B 站参考适配依赖交互式原生 biliup，首版不作为已支持平台展示。
- 编写 `docs/architecture.md` 与共享类型；引擎通过随机 loopback 端口和临时 bearer token 由桌面宿主代理，账号/session 加密保存，任务提交前写入持久状态。
- 平台接入与任务队列正在开发。尚未执行真实账号发布；不复制参考仓库的账号、cookie 或 token 缓存。

### A2 · 首版功能与隔离测试

- 已实现 React 的文章／视频工作台、素材导入、Markdown 预览、账号管理、批量发布前检查、任务结果及设置；Tauri 提供受限代理、文件选择、外部平台链接和单实例管理。
- 引擎已实现 SQLite 内容库、素材复制、不可变批次快照、请求幂等、串行队列、取消／局部重试、重启恢复；平台提交前等待数据库持久化 ACK。
- 账号凭据和浏览器会话通过系统凭据库保护的 AES-GCM 保存；每个 worker 独立进程和临时目录，具有总时限及清理流程。
- 已接入文章 4 个、视频 3 个平台；文章／视频适配隔离测试 30 项通过，公众号 HTTP mock 测试 50 项通过。核心集成测试最终 17 项通过；真实账号和真实平台发布尚未验收。
- 初次集成测试发现 retry 返回值与文档不同，统一为 `{ok:true}`；独立审查复现“取消后缓冲事件导致队列退出”和“畸形转载 URL 返回 500”，代码修复并加入回归测试。
- 本机 Linux 首次 PyInstaller 引擎打包及启动／鉴权／状态／退出 smoke 通过；Rust 核心边界测试 6 项通过。完整原生编译、最终冻结引擎、界面验证和三目标 CI 仍在进行，不能将 Linux 结果当作 macOS/Windows 验收。
- 微信测试首次使用系统 Python 时缺少 pytest，改用项目 `.venv` 后 50 项通过；开发依赖均在 `engine/requirements-dev.txt`。
